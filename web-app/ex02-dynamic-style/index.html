Dynamic style

Compute numbers on a timer, then write them into element.style — color, size, position, rotation.

Idea

CSS files set the default look. TypeScript can override properties live: el.style.transform = …, el.style.backgroundColor = …. 

setInterval(() => {
  t += 0.05;
  box.style.left = `${120 + Math.sin(t) * 80}px`;
  box.style.transform = `rotate(${t * 40}deg)`;
}, 32);
