Canvas draw

Same sketching gesture as SVG, but paint with CanvasRenderingContext2D — beginPath, lineTo, stroke.

Idea

  • getContext("2d") — the drawing API
  • Match CSS size to canvas.width / height (device pixels)
  • Unlike SVG, individual strokes are not selectable in the DOM
  • Read main.ts — ui.ts only paints the page
