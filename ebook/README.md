# Labs Ebook

Generated HTML curriculum from `web-app/ex*/README.md` and
`demos/src/pages/ex*/README.md` labsheets.
**Markdown remains the source of truth** — do not hand-edit `src/generated/`.

## Open (students)

Double-click **[book/index.html](book/index.html)** (works offline via `file://`).

## Rebuild (maintainers)

Requires [`mdbook`](https://rust-lang.github.io/mdBook/) on PATH
(`cargo install mdbook`):

```powershell
pwsh -File .\ebook\scripts\build.ps1
```

This:

1. Stages labsheets → `src/generated/` + regenerates `src/SUMMARY.md`
2. Copies/stages `web-app/sdk/README.md` → `src/sdk/index.md`
3. Downloads `theme/mermaid.min.js` if missing (offline Mermaid)
4. Runs `mdbook build` → `book/`

Smoke / coverage:

```powershell
pwsh -File .\ebook\scripts\smoke.ps1
```

## Layout

| Path | Role |
|------|------|
| `src/introduction.md`, `reading-order.md`, `boards-and-caps.md`, `flash-firmware.md` | Curated front matter |
| `src/tracks/*.md` | Track hubs |
| `src/sdk/index.md` | Staged `@sdk` reference |
| `src/generated/` | Staged labsheets (build output of stage script) |
| `src/SUMMARY.md` | Sidebar TOC (regenerated by stage) |
| `theme/ebook.css`, `ebook.js` | Workshop look + Mermaid bootstrap |
| `book/` | HTML site committed for class |
