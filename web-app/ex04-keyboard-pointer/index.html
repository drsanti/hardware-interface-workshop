Keyboard + pointer

Click the stage to place dots. Focus it, then use arrow keys — keydown and pointerdown.

Idea

  • pointerdown — finger / mouse / pen; use offsetX / offsetY for stage-local coords
  • keydown — arrows nudge the cursor; Escape clears; Enter drops a mark
  • Stage needs tabindex="0" so it can receive keyboard focus
  • Read main.ts — ui.ts only paints the page
