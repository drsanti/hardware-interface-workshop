hardware-interface-workshop / web-app

Vanilla track

Start here if you are new to the browser: plain HTML, CSS, and TypeScript — no React yet.

How to run

  1. cd web-app
  2. vp install (first time)
  3. vp dev → http://localhost:5174/
  4. Pick one exercise below.

Do not open HTML via file://. React board demos: cd ../demos then vp dev (port 5173).
